# Voice Assistant Web Project

## وصف المشروع
هذا المشروع عبارة عن موقع إلكتروني لمساعد صوتي، ويتكون من واجهة أمامية وملفات خلفية لمعالجة طلبات المساعد وربطها بخدمة Gemini API.

## ملفات المشروع
- `index.php` — الصفحة الرئيسية للموقع.
- `style.css` — تنسيق وتصميم الواجهة.
- `app.js` — أكواد JavaScript والتعامل مع واجهة المساعد وإرسال الطلبات.
- `api/chat.php` — ملف PHP المسؤول عن استقبال الطلبات والتواصل مع Gemini API.

## رفع الملفات على السيرفر
تم رفع ملفات المشروع إلى السيرفر، وتشمل ملفات الواجهة الأمامية والخلفية.

## المشكلة التي ظهرت
عند محاولة إرسال رسالة إلى المساعد ظهر خطأ أثناء الاتصال بالخادم، مما يدل على وجود مشكلة في معالجة طلب الاتصال بين الواجهة وملف PHP.

## حل المشكلة
تم تعديل ملف `api/chat.php` ليعمل كواجهة API تستقبل طلبات POST بصيغة JSON، ثم تعالج الـ prompt وترسل الطلب إلى Gemini API، وبعد ذلك تعيد النتيجة إلى الواجهة بصيغة JSON.

كما تم استخدام ملف إعدادات منفصل `config.php` لحفظ مفتاح Gemini API وعدم وضع المفتاح السري مباشرة داخل المستودع العام على GitHub.

## GitHub
تم رفع ملفات المشروع النهائية إلى مستودع GitHub، مع تنظيم ملف `chat.php` داخل مجلد `api`.
